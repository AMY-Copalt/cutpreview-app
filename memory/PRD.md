# CutPreview — PRD

## Overview
High-fidelity Expo (React Native) mobile prototype to try, customize, and share
haircut ideas on a stylized 3D avatar. Arabic (RTL) default, English toggle.
No auth; local-only data (AsyncStorage). Images & avatar generation are mocked.

## Milestones
- **M1 (current):** 3D avatar viewer + style library + part-based editor + version saving.
- M2: Compare (before/after), simulated friends feedback, barber sheet with auto specs.
- M3: Onboarding, selfie capture mock, color/beard try-on, profile setup.

## Architecture
- Expo Router tabs: `library`, `editor`, `versions`, `profile`; `index` = avatar picker.
- State: tiny zustand-like store (`src/store.ts`) persisted to AsyncStorage.
- i18n: `src/i18n.ts` (ar/en), Arabic default. Fonts: Cairo loaded locally from
  `assets/fonts/Cairo-Regular.ttf` / `Cairo-Bold.ttf` (variable font).
- Theme: `src/theme.ts` (dark-first, gold accent).

## 3D Avatar rendering (IMPORTANT)
- `expo-gl` + `three` render BLACK inside Expo Go on Android (native GL surface
  issue under New Architecture); works on web only. Confirmed on 2 devices.
- **Current solution:** the three.js scene runs inside a `react-native-webview`
  (WebGL via device browser engine). HTML is generated by
  `src/components/avatarSceneHtml.ts` and loads three r128 UMD from a CDN.
  RN drives it via `injectJavaScript(window.__update(...))`; WebView posts
  `{type:'ready'|'error'}` back.
- **2D fallback:** `src/components/Avatar2DFallbackView.tsx` (react-native-svg)
  shows a schematic head reacting to region/length/color when WebGL/CDN fail or
  no `ready` within 9s. `AvatarViewer3D.tsx` orchestrates webgl ↔ fallback.
- Note: react-native-webview is NOT reliable on web preview (no bridge) → web
  always drops to 2D after the 9s timer. On a real device the WebGL path works.

## Key files
- `app/(tabs)/editor.tsx` — 3D canvas + region chips + part editor sheet + save.
- `src/components/AvatarViewer3D.tsx` — WebView/2D orchestrator (public API: default export + `QuickView` type).
- `src/components/avatarSceneHtml.ts` — three.js scene HTML (WebView).
- `src/components/Avatar2DFallbackView.tsx` — SVG fallback.
- `src/components/PartEditorSheet.tsx`, `RegionChipBar.tsx`, `Slider.tsx`.
- `src/data/{regions,styles,avatars}.ts`, `src/store.ts`, `src/i18n.ts`, `src/theme.ts`.
